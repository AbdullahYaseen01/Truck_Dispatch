# FreightTech Hub

Premium all-in-one carrier support website for FreightTech Hub — dispatch, compliance, insurance, factoring, and back-office services for owner-operators and fleets across the United States.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Pages

- `/` — Home
- `/about` — About Us
- `/services` — Services
- `/equipment` — Equipment We Dispatch
- `/why-us` — Why Choose Us
- `/carrier-signup` — Carrier Sign-Up
- `/contact` — Contact Us

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm start
```

## Deploy

Configured for Vercel. Connect the GitHub repository or run:

```bash
npx vercel --prod
```
